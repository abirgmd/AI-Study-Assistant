AI STUDY ASSISTANT — PHP + MYSQL

Version française, palette bleue, rôle unique : étudiant.

INSTALLATION AVEC XAMPP (WINDOWS)
1. Installez XAMPP avec PHP 8.1 ou supérieur.
2. Décompressez ce dossier dans C:\xampp\htdocs\ai-study-assistant
   index.php, app, config, database et public doivent être directement dans ce dossier.
3. Dans XAMPP Control Panel, démarrez Apache et MySQL.
4. Ouvrez http://localhost/phpmyadmin puis l’onglet Importer.
   Choisissez database/schema.sql et cliquez sur Exécuter.
   La base ai_study_assistant et ses tables sont créées.
   Si la base existe déjà, réimportez ce fichier : seule la table quizzes est ajoutée.
5. Copiez config/database.example.php vers config/database.php.
   XAMPP local : host=127.0.0.1, port=3306, database=ai_study_assistant,
   username=root, password vide (si vous ne l’avez pas modifié).
6. Ouvrez http://localhost/ai-study-assistant/public/signup.php
7. Créez votre compte étudiant. Vous arrivez sur votre accueil.
8. Testez « Se déconnecter », puis reconnectez-vous.

IMPORTANT
Ne double-cliquez pas sur les fichiers PHP. Ouvrez l’adresse localhost ci-dessus.
Toutes les fonctionnalités serveur nécessitent Apache/PHP et MySQL actifs.
Si Apache utilise un autre port, ajoutez-le à localhost (exemple : localhost:8080).
Aucun npm install ni Composer n’est nécessaire.

AUTRE OPTION (PHP ET MYSQL DÉJÀ INSTALLÉS)
- Importez database/schema.sql dans MySQL.
- Préparez config/database.php comme ci-dessus.
- Dans le dossier du projet : php -S localhost:8000 -t public
- Ouvrez http://localhost:8000/signup.php

EXTENSIONS PHP
pdo_mysql, fileinfo, zip, curl et mbstring doivent être activées dans php.ini.
(curl et mbstring servent à la génération de quiz.)
Pour DOCX, décommentez extension=zip si nécessaire et redémarrez Apache.
Pour des fichiers de 10 Mo, configurez dans php.ini :
upload_max_filesize = 10M
post_max_size = 12M
Puis redémarrez Apache. Le fichier .user.ini fourni est pris en compte avec PHP-FPM/CGI,
mais pas toujours par le module Apache de XAMPP.
Le serveur doit pouvoir écrire dans storage/courses.

QUIZ IA (FACULTATIF : CLÉ API REQUISE)
1. Copiez config/groq.example.php vers config/groq.php.
2. Renseignez 'api_key' : clé OpenAI, ou clé Groq avec base_url https://api.groq.com/openai/v1.
   'model' génère les QCM, vrai/faux, fiches et questions reliées.
   'vision_model' lit les images pour « Questions avec image » (ex. qwen/qwen3.8-27b sur Groq).
   Vous pouvez aussi définir la variable d’environnement OPENAI_API_KEY.
   Sans clé, le quiz affiche un message explicite ; le reste de l’application fonctionne.
3. Sur l’accueil, « Quiz de révision » : 1) choisissez le cours, 2) choisissez le type de quiz
   (la liste vient du serveur), 3) cliquez sur « Générer le quiz ». Un quiz compte 5 éléments.
   Les cours PDF restent affichés mais ne servent pas encore à générer un quiz.
4. Pour essayer, importez samples/cours-apprentissage-supervise.txt.
   « Questions avec image » demande un DOCX contenant des images PNG ou JPEG (1 Mo maximum chacune).
Les PDF ne servent pas encore à générer un quiz (ils restent importables).
Le texte du cours est envoyé au fournisseur IA configuré : n’utilisez que des cours
que vous pouvez transmettre à ce service.

CE QUI FONCTIONNE
- Protection des données : e-mails, téléphones, IBAN et liens sont masqués avant tout
  envoi au service IA ; les réponses de l’IA sont validées (JSON strict) avant affichage.
- Création de comptes étudiants, connexion, déconnexion.
- Mots de passe hachés et requêtes préparées PDO.
- Sessions et protection CSRF ; limitation à 10 tentatives d’authentification
  par adresse IP sur 15 minutes (les créations de comptes comptent aussi).
- Chaque étudiant voit uniquement ses documents et ses quiz.
- Import de PDF, TXT et DOCX, maximum 10 Mo, téléchargement protégé.
- Les métadonnées sont dans MySQL ; les fichiers dans storage/courses.
- Recherche : mots ou notions cherchés dans le texte de vos cours TXT et DOCX, sans IA.
  Les PDF ne sont pas lus par la recherche.
- Assistant de cours : réponse à votre question à partir du texte d’un cours TXT ou DOCX,
  via le service IA configuré (même clé que le quiz).
- Quiz : QCM, vrai/faux, fiches recto/verso, questions reliées et questions avec image,
  générés à partir de vos cours TXT ou DOCX (voir QUIZ IA), vérifiés, puis enregistrés
  dans votre espace pour être refaits. Les fiches ne sont pas notées.

PÉRIMÈTRE
Un seul rôle applicatif : étudiant. Plusieurs étudiants peuvent créer leur compte,
chacun avec son espace. Aucun administrateur ni enseignant.
L’authentification et les données sont réelles. Le résumé de cours et la recherche
sémantique restent à brancher. Le score de chaque quiz corrigé est
recalculé par le serveur et enregistré ; l’accueil affiche le score moyen réel.
Il n’y a pas encore de récupération de mot de passe ni de vérification d’e-mail.

DÉPLOIEMENT
Pour un vrai hébergement, utilisez HTTPS, un utilisateur MySQL dédié à cette base,
et un mot de passe fort. Faites pointer la racine du serveur vers public/.
Ne rendez jamais app/, config/, database/ ou storage/ accessibles sur Internet.
Les .htaccess inclus bloquent ces dossiers avec Apache lorsque AllowOverride est activé.
Sauvegardez ensemble la base et storage/courses.

DÉPANNAGE
- Erreur de base : vérifiez l’import SQL, MySQL actif, le port et database.php.
  « Unknown database 'ai_study_assistant' » : la base n’existe pas (ou plus) ; réimportez
  database/schema.sql comme à l’étape 4.
- Page PHP téléchargée au lieu d’être affichée : PHP n’est pas exécuté par le serveur.
- Upload impossible : limites php.ini, extensions et permission de storage/courses.
- Trop de tentatives : attendez 15 minutes.
- Session expirée : rechargez la page et recommencez.
- Quiz : « Clé IA absente » : renseignez config/groq.php ; « Clé refusée » : vérifiez la clé
  et le modèle. Après modification de config/groq.php, attendez quelques secondes.
- Quiz « Questions avec image » : « ne contient pas d’image exploitable » : importez un DOCX
  avec des images PNG ou JPEG de 1 Mo au plus. Une erreur de modèle évoque vision_model.
- Quiz : une réponse « json_validate_failed » de Groq est retentée automatiquement une fois.
